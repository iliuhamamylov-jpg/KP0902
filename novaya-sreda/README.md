# Новая среда

Учебный сайт строительной компании: Node.js, Express и PostgreSQL. Страницы: главная, проекты, проект, квартиры, квартира, ипотека, новости, о компании и контакты. Фильтры работают в браузере, заявки сохраняются в базе. Ипотечный калькулятор рассчитывает аннуитетный платёж; ставки демонстрационные.

## Запуск
1. Установите Node.js (18 или новее) и PostgreSQL.
2. Создайте пустую базу `novaya_sreda` через pgAdmin или командой `createdb novaya_sreda`.
3. Скопируйте `.env.example` в `.env` и укажите правильные имя пользователя, пароль, адрес и порт PostgreSQL в `DATABASE_URL`.
4. В папке проекта выполните `npm install`, затем `npm run db:init`, затем `npm start`.
5. Откройте http://localhost:3000. Повторный запуск инициализации не дублирует демонстрационные записи.

## База данных
Таблицы: `projects` (комплексы), `apartments` (квартиры, связаны с комплексом), `news`, `mortgage_programs`, `requests` (заявки, могут ссылаться на квартиру). Заявки можно посмотреть в pgAdmin или запросом `SELECT * FROM requests ORDER BY created_at DESC;`.

## Git и GitHub
В папке проекта выполните `git init`, `git add .`, `git commit -m "Создан сайт строительной компании"`. Создайте пустой репозиторий на GitHub, затем добавьте его адрес командой `git remote add origin АДРЕС_РЕПОЗИТОРИЯ`, выполните `git branch -M main` и `git push -u origin main`. Файл `.env` с паролем не попадёт в Git. Удалённый репозиторий автоматически не создаётся.

Изображения загружаются с Unsplash, поэтому для них нужен интернет. Данные компании и контакты вымышлены. Отчёт не входит в текущий этап.
